# Sound assets

These are **functional synthesized placeholders** (audible tones/chimes, 22.05kHz
mono 16-bit) so the game actually makes sound. Replace each with a polished
royalty-free clip of the same filename for production (keep `.wav`, or switch
all to `.mp3` and update `SoundService` filenames).

| File             | Cue                      | Suggested length |
|------------------|--------------------------|------------------|
| `bg_music.mp3`   | looping lobby/background music | full track, seamless loop |
| `spin_loop.wav`  | reels spinning (loops)   | 0.3–1.0 s, seamless |
| `reel_stop.wav`  | each reel / coin lands    | < 0.2 s click    |
| `coin.wav`       | coins landing in balance  | 0.2–0.4 s        |
| `win.wav`        | normal win chime         | 0.3–0.6 s        |
| `bigwin.wav`     | BIG/MEGA/EPIC fanfare    | 0.8–1.5 s        |
| `tap.wav`        | button press             | < 0.1 s          |

Good free sources: freesound.org (filter CC0), pixabay.com/sound-effects,
mixkit.co. Drop the files in this folder with the exact names above and
hot-restart — no code change needed.

The placeholders were generated by a small pure-stdlib Python script
(sine/square/saw tones with envelopes); regenerate or replace freely.
